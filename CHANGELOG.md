# Changelog

## 1.1.0 - 2026-04-20

- Добавлен новый режим расписания задачи по выбранным дням внутри периода.
- Подготовлена схема БД для хранения выбранных дат расписания.
- Таймлайн и статистика периода учитывают нагрузку по конкретно выбранным дням.
- Визуализация задач по выбранным дням разбита на отдельные сегменты с мягкой связкой между ними.
- Пересечения задач разделены на допустимые по часам и реальные перегрузы.
- Выход из режима редактирования добавлен по сохранению, отмене и клику в пустую область таймлайна.

## 1.0.0 - 2026-04-20

- Перенос приложения с одного HTML-файла на Vite + React + TypeScript.
- Подключение Supabase через env-конфиг и обновленная структура проекта.
- Новый таймлайн с режимами "Неделя" и "Месяц", навигацией по периодам и возвратом к текущей дате.
- Планирование загрузки по часам и дням с учетом рабочих дней Армении.
- Поддержка режимов расписания задачи: "Авто" и "Часов в день".
- Подготовка и применение миграции под новую структуру данных задач.
